# AGENTS.md

**This is NOT the Next.js you know.** This version may have breaking changes: APIs, conventions, and file structure may differ from your training data. Read the relevant guide in `node_modules/next/dist/docs/` before writing any code. Heed deprecation notices.

## Confirmed differences in this project's Next.js (16.3.0)

Verified against `node_modules/next/dist/docs/` on this repo, not from memory:

- `LayoutProps<'/'>` and `PageProps<'/work/[slug]'>` are **globally available** route-aware type helpers. Do not import them, and do not hand-roll `{ children: React.ReactNode }` or `{ params: Promise<...> }` prop types.
- Those helpers are generated by `next dev`, `next build`, or `next typegen`. A bare `tsc --noEmit` on a clean checkout fails because the types do not exist yet. Always run `next typegen` first. The CI workflow does this.
- `params` and `searchParams` are Promises and must be awaited.
- `next-env.d.ts` is generated and is gitignored. Never edit it.

## Hard constraints

- Static export only. No API routes, no server actions, no middleware, no ISR, no dynamic rendering, no runtime redirects. Every dynamic route needs `generateStaticParams`.
- GitHub Pages is the only host. There is no second platform and no manual deploy.
- No em dashes or en dashes anywhere: not in site copy, comments, commit messages, or documentation.
